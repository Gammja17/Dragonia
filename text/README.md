# 대사 시트

게임 안의 글(대사·제목·안내문)을 표 하나로 고치는 곳이다. 코드를 몰라도 된다.

## 고치는 법

1. `dialogue.csv` 를 연다. GitHub 에서 연필 버튼으로 바로 고쳐도 되고, 내려받아 엑셀·구글 시트로 열어도 된다
   (엑셀은 "CSV UTF-8" 로 저장, 구글 시트는 파일 → 다운로드 → CSV).
2. **대사** 열만 고친다. 파일·줄·원문 열은 되돌릴 때 자리를 찾는 열쇠라 건드리지 않는다.
3. 저장하고 `main` 에 올리면(커밋) 자동으로 코드에 반영되고, 1~2분 뒤 배포된다.

되돌리기 자동화가 실패하면(Actions 탭이 빨갛다) 원문을 못 찾은 줄이 적혀 있다. 그 줄은 파일에서 직접 고친다.

## 규칙

- 줄을 늘리거나 지울 수는 없다. 글만 바꾼다. 선택지 하나를 더 넣는 식의 구조 변경은 코드에서.
- `${c.name}` 같은 자리표시자는 그대로 둔다. 게임이 그 자리에 이름을 넣는다.
- 줄바꿈은 시트 칸 안에서 그대로 쓰면 된다(엑셀은 Alt+Enter).
- 같은 원문이 두 곳 이상이면 한 번에 다 바뀐다.

## 직접 돌리기

```
node tools/text-export.mjs   # 코드 → text/dialogue.csv
node tools/text-import.mjs   # text/dialogue.csv → 코드 (바뀐 줄만)
```
